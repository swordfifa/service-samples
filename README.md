# PACE — original sports interface and Lottie sample

Created by **swordFIFA with AI assistance** for capability review. This is an original demonstration, not a past paid client case. All metrics and route graphics are fictional.

For an offline copy, download [sport-motion-sample.html](sport-motion-sample.html) using its Raw button, save it as an HTML file, then open it in a modern browser. It includes the local Lottie renderer and animation data; there are no analytics, external fonts, images, or network calls. The GitHub file view displays the source; the live demo link below runs it in your browser.

[Open the live demo](https://swordfifa.github.io/service-samples/sport-motion-sample.html)

The sample shows three UI states and a vector completion animation: 320 × 320 pixels, 30 fps, 3 seconds. [completion.json](completion.json) is the standalone original vector animation (about 1.8 KB). Replay, frame inspection, and reduced-motion controls are included.

Checked in Chrome with Lottie Web 5.13.0: empty initial ring/check, partially drawn intermediate ring, complete ring/check, Finish interaction, and reduced-motion state. Native iOS/Android integration, Figma/After Effects source, and PAG/Spine/Rive support are not claimed. Workout controls use fixed simulated metrics.

The bundled third-party Lottie Web renderer is MIT licensed; its copyright notice and license are preserved inside the HTML. The interface and animation are original sample work. Paid project scope, source format, target renderer, acceptance, and payment require separate confirmation.

# Storyframe — standalone story-card editor demo

An original, AI-assisted interface sample by **swordFIFA**. This is a capability demo, not a paid client project or a claim of integration with a hosted story or chat service.

[Open the live demo](https://swordfifa.github.io/service-samples/story-template/) · [View the source](index.html)

The single HTML file demonstrates a Chinese-language editor and preview for a fictional story card: editable title, scene and narrative, theme and placement controls, desktop/mobile preview widths, and example action choices. It has no backend, makes no live model calls, and loads no external resources.

## Verification status

The recorded Chrome check in [`validation.json`](validation.json) covers initial rendering, theme changes, the mobile preview toggle, and local action feedback. The following behaviors remain unverified: configuration export, standalone HTML export, long-content layout, and import into SillyTavern or another runtime. No runtime compatibility claim is made.

## Run locally

Download `index.html` and open it in a modern browser. It is a standalone file; no build step or network service is required.

All characters, story text, and action choices are fictional demo content.

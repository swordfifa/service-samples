这个样例覆盖什么

三种展示风格、开场排版、状态栏开关与位置、行动选项、长内容和窄屏适配、静态 HTML 与配置导出。行动点击只展示本地反馈，不调用模型、不发送聊天消息。导出文件是独立网页和本工具配置，不是 SillyTavern 角色卡或插件；运行时样式隔离、卡片导入与 Agent 生成需要另行适配验证。
